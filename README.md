# CLI Banking Application

## Overview
A command-line banking application that simulates real-world banking operations.

## Features
- User Authentication
- Account Management (Checking and Savings)
- Deposit and Withdrawal Operations
- Transaction History Logging
- Balance Visualization

## Installation
```bash
git clone https://github.com/NyCores/Python.API.git
cd Python.API
pip install -r requirements.txt
python main.py
